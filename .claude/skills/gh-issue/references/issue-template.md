# 이슈 본문 템플릿

근거가 없는 항목은 `(작성 필요)`로 남긴다. 섹션 자체를 지우지는 않는다.

## feature / refactor / chore / docs

```markdown
## 배경
<왜 필요한지 1~3줄>

## 할 일
- [ ] <구체적인 작업 1>
- [ ] <구체적인 작업 2>

## 완료 조건
- <무엇이 되면 끝났다고 볼 수 있는지>

## 참고
<관련 파일, 링크, 이슈 번호 — 없으면 섹션 생략 가능>
```

## bug

```markdown
## 현상
<무엇이 잘못 동작하는지>

## 재현 방법
1. <단계 1>
2. <단계 2>

## 기대 동작
<원래 어떻게 동작해야 하는지>

## 환경
- OS / 버전 / 브랜치: (작성 필요)

## 할 일
- [ ] 원인 파악
- [ ] 수정 및 재발 방지 테스트 추가
```
