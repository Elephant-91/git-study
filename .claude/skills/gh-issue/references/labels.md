# 라벨 체계

이 정의는 `scripts/ensure_labels.py`의 `LABELS`와 동일하게 유지한다. 한쪽을 바꾸면 다른 쪽도 바꾼다.

## 유형 (type) — 이슈마다 정확히 1개

| 라벨 | 색 | 제목 태그 | 브랜치 prefix | 판별 키워드 |
|------|----|-----------|---------------|-------------|
| `type: feature` | `#a2eeef` | `[Feature]` | `feature` | 추가, 구현, 새 기능, 만들기, 지원, 도입 |
| `type: bug` | `#d73a4a` | `[Bug]` | `fix` | 오류, 에러, 버그, 안 됨, 깨짐, 잘못, 실패, 수정(결함일 때) |
| `type: docs` | `#0075ca` | `[Docs]` | `docs` | 문서, README, 주석, 가이드, 설명 보완 |
| `type: refactor` | `#cfd3d7` | `[Refactor]` | `refactor` | 리팩터링, 구조 개선, 정리(동작 변화 없음), 중복 제거 |
| `type: chore` | `#fef2c0` | `[Chore]` | `chore` | 설정, 의존성, 빌드, CI, 버전 업, 환경 구성 |

판단이 애매하면: 사용자에게 보이는 동작이 새로 생기면 feature, 기존 동작이 잘못됐으면 bug.

## 우선순위 (priority) — 이슈마다 정확히 1개

| 라벨 | 색 | 기준 |
|------|----|------|
| `priority: high` | `#b60205` | "급해", "긴급", "오늘", "장애", 서비스·데이터에 즉시 영향 |
| `priority: medium` | `#fbca04` | 기본값 (언급 없을 때) |
| `priority: low` | `#0e8a16` | "나중에", "여유 있을 때", "있으면 좋음" |
